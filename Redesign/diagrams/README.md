## Regenerate

```powershell
# from Redesign/diagrams — requires node; mermaid-cli fetched on demand
foreach ($f in Get-ChildItem src\*.mmd) {
  npx -y @mermaid-js/mermaid-cli -i $f.FullName -o "$($f.BaseName).svg" -c src\theme.json -b white
}
```

The flagship `aegisops-target-architecture.svg` is **not** regenerated by the loop above — edit it
directly (or re-derive from 02 §2.1) and rasterize the PNG at 2× with any headless-Chrome
screenshot of the SVG. If a content change lands in 02 §2.1, update the hand-authored SVG in the
same PR — CI reviewers should treat a divergence as a defect.

Styling: `src/theme.json` (shared mermaid theme — Segoe UI, muted blue palette, white background).
